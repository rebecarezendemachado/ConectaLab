🧪 Matéria Reativa

Como você deseja abrir o sistema?

Aplicações modernas em React precisam de um servidor web local ativo ou acesso direto. Escolha uma das opções abaixo:

1. Executar pelo iniciar.bat (Recomendado)

Dê 2 cliques no arquivo iniciar.bat na pasta do projeto.

⚡

2. Abrir Servidor Local (http://localhost:3000)

Se o servidor já estiver rodando via terminal, VS Code ou .bat.

🌐

3. Abrir pelo Apache (XAMPP)

Se você utiliza o XAMPP em C:\xampp\htdocs\ com o Apache ativo.

📦

4. Acessar Online Imediatamente

Roda direto na nuvem sem precisar instalar Node, XAMPP ou nada no PC.

☁️
Pelo VS Code Terminal: npm run dev

Dica: Para rodar no VS Code com o Live Server, abra qualquer arquivo .html e clique com o botão direito em "Open with Live Server".
