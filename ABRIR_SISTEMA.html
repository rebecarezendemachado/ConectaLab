🧪 Matéria Reativa

Como você deseja abrir o sistema?

O sistema precisa iniciar o servidor local para entrar com segurança e salvar os dados. No Windows, use o arquivo iniciar.bat.

1. Executar pelo iniciar.bat (Recomendado)

Dê 2 cliques no arquivo iniciar.bat na pasta do projeto.

⚡

2. Abrir o sistema

Use este botão depois que o servidor tiver sido iniciado pelo arquivo iniciar.bat.

🌐
Pelo VS Code Terminal: npm run dev

Requer Node.js 22.13 ou superior. Servidores estáticos, XAMPP ou Live Server não oferecem o login e o banco de dados deste sistema.
